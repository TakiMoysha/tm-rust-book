Cargo.toml

[dependencies]
surrealdb = { version = "3.2", features = ["kv-mem"] } # kv-mem: in-memory engine
tokio     = { version = "1",   features = ["macros", "rt-multi-thread"] }
serde     = { version = "1",   features = ["derive"] }
anyhow    = "1"

Feature flags choose what gets compiled in: kv-mem (in-memory), kv-rocksdb (embedded file), protocol-ws (remote server). docs ↗

Engines — the type parameter decides

EngineConnectWhen
In-memorySurreal::new::<Mem>(())Dev, tests, demos. Zero setup.
RocksDB fileSurreal::new::<RocksDb>("path")Embedded persistence, no server.
WebSocketSurreal::new::<Ws>("localhost:8000")Real server via WS.
Any (late-bound)Surreal::init() + .connect(url)Endpoint decided at runtime — good for a static handle.

The turbofish isn't decoration: it selects the backing engine at compile time. [embedding]

Lifecycle of every program

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let db = Surreal::new::<Mem>(()).await?;      // 1. connect
    db.use_ns("explorer").use_db("dev").await?;   // 2. scope

    // 3. operate: create / select / query / update / delete
    Ok(())
}
  • #[tokio::main] starts the async runtime — every SDK call is .await-able.
  • use_ns/use_db scope all later operations; do it once after connecting.

Shared static handle

static DB: LazyLock<Surreal<Any>> = LazyLock::new(Surreal::init);

// once at startup:
let endpoint = env::var("DB_ENDPOINT").unwrap_or_else(|_| "mem://".into());
DB.connect(endpoint).await?;
DB.use_ns("explorer").use_db("dev").await?;

LazyLock closures can't .await, so init() hands back an unconnected client; connect() binds the engine at runtime. [init]

CRUD with typed structs

#[derive(Debug, Serialize, Deserialize)]
struct Person {
    name: String,
    role: String,
}

// CREATE — always ONE record per call → Option<T>
// (works with table name or ("table", id); annotation drives extraction)
let made: Option<Person> = db.create(("person", "tobias"))
    .content(Person { name: "Tobias".into(), role: "learner".into() })
    .await?;

// INSERT — many records → Vec<T>
let many: Vec<Person> = db.insert("person")
    .content(vec![Person { name: "A".into(), role: "x".into() }])
    .await?;

// SELECT ALL
let people: Vec<Person> = db.select("person").await?;

// SELECT ONE
let one: Option<Person> = db.select(("person", "tobias")).await?;

// RAW SurrealQL (check() turns query errors into Err)
let mut res = db.query("SELECT * FROM person WHERE role = $role")
    .bind(("role", "learner"))
    .await?
    .check()?;
let hits: Vec<Person> = res.take(0)?;

Serde bridges struct ⇄ record: derive Serialize to write, Deserialize to read. Extra stored fields are ignored on read unless the struct opts into strictness. [methods]
