Lesson 0002 · tui-hybrid-search · data layer

Schema & the shared DB handle

Today you finish the data layer properly: one static DB handle any function can use, and a real enforced schema — replacing your parked infra/mod.rs sketch.

Why this matters

Your first infra/mod.rs draft asked three questions without knowing it:

  1. How do functions share the DB? Your sketch reached for a static LazyLock<Surreal<Client>> — right instinct.
  2. Why did it fight back? You can't .await inside LazyLock::new — its closure is synchronous. That's what DbGuard/fn startup were groping toward.
  3. Do I need is_schema_exists()? No — SurrealQL's DEFINE … IF NOT EXISTS is idempotent, so we simply define on every boot.

The three ideas you need

  1. The init/connect split. Surreal::init() hands back an unconnected client — cheap, no I/O, safe inside a static. Later, in async land, .connect(endpoint) binds the engine at runtime.[1]
  2. The endpoint is data, not code. Read it from an env var with a mem:// fallback. Today that means embedded; when the explorer targets a live server you change an environment variable, not your code.[1]
  3. Schemas are definitions, not migrations. SCHEMAFULL tables reject fields you haven't declared with DEFINE FIELD — exactly the predictability a DB explorer needs to render results.[2]
Everything below is compressed on the cheat sheet under “Shared static handle”.

Do it now (~20 min)

  1. Rewrite all of src/infra/mod.rs: 
    use std::sync::LazyLock;

use surrealdb::engine::any::Any;
use surrealdb::Surreal;

pub static DB: LazyLock<Surreal<Any>> = LazyLock::new(Surreal::init);

pub async fn init() -> anyhow::Result<()> {
    let endpoint = std::env::var("DB_ENDPOINT").unwrap_or_else(|_| "mem://".into());
    DB.connect(endpoint).await?;
    DB.use_ns("explorer").use_db("dev").await?;
    define_schema().await?;
    Ok(())
}

async fn define_schema() -> anyhow::Result<()> {
    DB.query(
        "DEFINE TABLE IF NOT EXISTS person SCHEMAFULL;
         DEFINE FIELD IF NOT EXISTS name ON person TYPE string;
         DEFINE FIELD IF NOT EXISTS role ON person TYPE string;",
    )
    .await?
    .check()?;
    Ok(())
}

    Note .check(): raw queries don't fail by default — it converts statement errors into a normal Err.[3]

  2. Update src/main.rs to declare the module and use the shared handle: 
    mod infra;

use serde::{Deserialize, Serialize};
use surrealdb::types::SurrealValue;

#[derive(Debug, Serialize, Deserialize, SurrealValue)]
pub struct Person {
    pub name: String,
    pub role: String,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    infra::init().await?;

    let made: Option<Person> = infra::DB
        .create("person")
        .content(Person {
            name: "Tobias".into(),
            role: "learner".into(),
        })
        .await?;
    println!("created: {made:?}");

    let people: Vec<Person> = infra::DB.select("person").await?;
    println!("people: {people:?}");

    Ok(())
}

    Fields became pub: they're now part of the crate's public surface, used across modules. The old local let db = …, get_theme, and unused imports go away — warnings gone.

  3. Run it: cargo run — same output as lesson 0001, but now through the shared handle with an enforced schema behind it. 
    created: Some(Person { name: "Tobias", role: "learner" })
people: [Person { name: "Tobias", role: "learner" }]
  4. Predict, then prove the schema bites. Append this before Ok(()). Before running, say out loud what check() will return. 
    let bad = infra::DB
    .query("CREATE person SET name = 'eve', role = 'tester', level = 9")
    .await?
    .check();
println!("bad: {bad:?}");

    SCHEMAFULL should refuse the undeclared level field. Confirm, then delete the experiment.
